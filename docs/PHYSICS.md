# Physics assumptions and limits

The detector receives its original pixels and preprocessing. The inspection layer operates independently; no slant-corrected detector route is enabled and no filtering deletes predictions. Scores remain uncalibrated. Quality, geometry, uncertainty and review priority are separate fields.

Bottom tracking consumes one supported raw SSS window (at most 512 by 32768 samples), not a full recording array. Median blocks propose sustained first-return steps; isolated spikes are resisted, multiple steps remain ambiguous, constant/dropout rows are invalid. Acoustic shadows are not classified automatically as missing data. Per-ping candidates survive alongside accepted traces. Range uses explicit sample count, near/far orientation, metre extents and port/starboard. Nonzero unresolved delay, invalid extent or unknown calibration prevents reliable altitude. Calibration must establish the sound-speed/range interpretation and sample offset; a positive SlantRange field alone is insufficient.

A sustained transition can also be a shadow exit or target edge. The water-column interpretation therefore requires independent verification; the algorithm alone does not establish it. A first return is only vertical altitude under independently verified level-sensor and flat-seabed assumptions. Configuration requires an explicit maximum vertical rate in m/s from acquisition knowledge; sample support supplies an additional discretization allowance. Trace discontinuities are rejected and gaps break continuity. No hidden interpolation conceals motion. Manual source-bound corrections retain their provenance and do not bypass reliability gates. Port/starboard disagreement invalidates altitude when compared at identical source/ping IDs; a user-supplied tolerance must have a physical basis. `render_trace` leaves the raw intensity waterfall visible: orange candidates, lime usable estimates, magenta uncertain traces, red invalid row marks. Display contrast does not modify inference input.

Strict positioning reuses Phase 1 pixel edges, row/sample conventions, WGS84 geodesics and always-XY CRS transforms. At a box centre slant range r and seabed altitude h give ground range sqrt(r²−h²); r<h has no flat-seabed intersection. Port is true heading−90°, starboard +90°. SSS positioning is rejected for FLS fan imagery. Affine/GeoTIFF coordinates retain their own source-bound transform.

Measured, estimated and manually supplied altitude require explicit provenance. Estimated values also need reliable-under-declared-assumptions status. Vessel GPS requires a verified horizontal sensor offset (forward/starboard in metres), never an invented cable angle. Navigation interpolation follows a WGS84 geodesic, shortest heading arc, explicit timezone, same sensor reference and a caller-specified maximum time gap; extrapolation is prohibited. Sensor depth below surface is never substituted for altitude.

The optional uncertainty model accepts deterministic maximum errors for navigation, heading, altitude and slant range, plus sensor-offset error when relevant. Its horizontal bound sums a navigation disk, worst interval ground-range error and heading chord error. This is not a confidence probability. It excludes unknown terrain, attitude and metadata biases. Near-nadir intervals crossing the invalid slant domain yield unknown uncertainty with a sensitivity warning. Missing inputs yield unknown, never an invented numerical radius. Coordinates remain estimates and real field accuracy is unvalidated. Image footprints are not measured object dimensions or object heights.
