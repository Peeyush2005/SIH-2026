# Ocean website update

BluEcho's homepage now introduces the problem, the solution, the available
features and the product's focus on private, reviewable, source-bound evidence.
The navigation and hero use deep ocean blue and sea-glass accents. A custom SVG
and CSS sonar illustration supplies the visual identity; it is explicitly marked
as an illustration and does not display invented model results or coordinates.

The six feature descriptions cover sonar specialists, acoustic context, human
review, metadata-backed maps, batch inspection and portable reports. Model
limitations remain accessible. No comparative accuracy, universal detection,
material identification or verified net support is added by this redesign.

The homepage retains progressive upload configuration and avoids numerical
statistics or a model-card gallery. The header leads to inspection, reports and
model information. Operator controls, source images and scientific results retain
their existing behavior.

Motion uses slow CSS transforms, with a pause control, reduced-motion support and
pausing when the tab is hidden. The illustration unmounts when the inspection
workspace opens. No animation library, remote font, stock imagery or new cloud
dependency was added. Native system typography and increased text contrast keep
the working surfaces readable.

Validation includes desktop/mobile screenshots, motion-control and reduced-motion
checks, progressive upload and navigation checks, real browser inference against
the unchanged pipeline reference, review persistence, maps, PDF/structured
exports, batch inspection and the local dashboard regression. Test receipts are
stored in `ocean-website-verification.json`. This release changes presentation;
existing model evidence and measured limitations remain in their model cards.
