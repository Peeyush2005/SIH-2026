# Canonical geolocation, version0.1.3

Public box geolocation uses `bluecho.phase1.geography.geotag_box`; strict point positioning uses `position_pixel` and `bluecho.inspection.geometry.position` with the same implementation and pixel convention. The old permissive vessel approximation and implicit raw geometry are no longer used by reports. This is a deliberate safety migration; boxes/scores/thresholds are unchanged.

Affine: [a,b,c,d,e,f] maps original continuous pixel-edge x,y to CRS x=a*x+b*y+c,y=d*x+e*y+f. Default pixel_convention=pixel_edge; pixel_center means integer coordinates in the supplied transform denote sample centers and production edge coordinates subtract0.5 before transformation. GeoTIFF raster transforms use pixel edges. always_xy forces easting/longitude first. Pyproj converts declared CRS units to WGS84 longitude,latitude. Representative center and16sampled boundary points are mapped. Antimeridian-crossing or self-intersecting/degenerate footprints are omitted with reasons, not emitted as invalid polygons.

Raw SSS: explicit modality, timezone timestamp, timestamp_alignment_verified, calibration_verified, true heading and valid sensor reference required. Slant requires flat_seabed_verified, level_sensor_verified and positive altitude with measured/estimated/manually_supplied provenance. Estimated altitude additionally requires reliable_under_declared_assumptions. Ground-range samples require ground_range_verified, and are not converted again or forced to have altitude. Nonzero time delay requires resolved range origin. Sensor/vessel offsets must be explicitly verified; no arbitrary tow cable angle. No FLS fan conversion. Heading wraps modulo360; sentinels/nonfinite values rejected.

Under those assumptions, ground=sqrt(slant²-altitude²), projected perpendicular to heading on the declared side using WGS84 geodesics. Near-nadir error intervals touching the invalid domain give unknown uncertainty and a reason. Explicit navigation/heading/range/altitude bounds produce a conservative engineering bound, not a probability interval. No uncertainty inputs means unknown. Affine horizontal_error_bound_m is a supplied bound, not measured accuracy. Timestamp interpolation is geodesic and limited by max_gap_s; no extrapolation. Footprints/tracks do not bridge missing rows or time gaps(default2s).

Metric dimensions are cross-image and along-image midpoint spans of the detection-box footprint in metres, not actual object length,width or height. No shadow-height inference. JSON/CSV retain every candidate; detections.geojson uses null geometry for unlocated candidates. Separate footprints, tracks, processed image extent, quality and unassessed files avoid depicting tracks as debris maps. Processed image extents do not establish observed seafloor coverage.

`geotag_saved` binds the exact original source hash plus saved decoded pixel hash/dimensions, validates the sidecar, and regenerates reports without inference. Original predictions remain in original_predictions.json. Metadata provenance includes filename/hash, with measured/manual/estimated inputs separately identified.
