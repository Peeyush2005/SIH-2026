# Phase 2 geometry/reporting contract

Consume results.json, detections.csv, original.png, annotated.png, crops/, contexts/, quality.png and recording.json. Candidate IDs bind source SHA256, window, model hash and raw prediction. Coordinates use original decoded image continuous pixel-edge xyxy (top-left origin; x right, y down; right/bottom exclusive, clipped positive area). Scores are raw model score times100, uncalibrated. Review priority and positioning uncertainty are separate. No default verifier filtering.

Each candidate retains source filename/hash, window/channel/ping/sample references, native class, explicit null mapped class when no mapping is asserted, model version/hash, image size, pixel dimensions, evidence paths and review state. Window metadata for XTF remains in decoded/window_*/decoded_metadata.json; each row includes ping ID, packet offset, timestamp, side, raw sensor/vessel fields, range/time-delay and altitude availability. Raw arrays retain original samples. Source-NMS provenance for pipeline is model-inference-provenance.json: tile crop offsets, native tile boxes and retained source boxes. Rendering pads right/bottom without scaling; network letterbox mapping remains in the unchanged adapter. Pre-tile-NMS candidates are not available. No stitching policy changed.

Keep image boxes, sensor tracks, target estimates, approximate image footprints, physical object dimensions and positional uncertainty distinct. Missing geographic coordinates remain null with reasons. Vessel/sensor positions are not object positions. No real field location accuracy or reliable XTF bottom altitude established. No new geometry is implemented in this phase.

XTF: --channel required; --start-ping is zero-based sonar-packet ordinal; --max-pings 0 requests all remaining supported pings on that channel; --chunk-pings 1..512. Defaults process128pings explicitly, not a full recording. recording.json lists successfully inferred windows. partial_coverage.json reports decoding only and must never be counted as completed inference. Cancellation exits130; malformed input is an error, not a negative detection. Completed files survive interruption. Other channels stay unassessed.

Supported decoded images: PNG/JPEG/BMP/PBM/TIFF (8-bit via existing loader), GeoTIFF with geospatial extra. Maximum30millionpixels/2GiB per file. XTF uint8/uint16 supported sides, ≤6header channels, ≤32768samples/ping, ≤32MiB packets. No SL2 or raw ARIS decoder; FLS_ARIS refers to decoded images. Raw input is never modified. Quality striping/low-signal observations do not establish dropout or identity.

Use `bluecho boxes image.pbm --registry /absolute/registry --model sss-pipeline-v3 --modality SSS_LF --output /absolute/fresh-report`. Python: `RecordingEngine(registry).predict(source, output, model_ids=["sss-pipeline-v3"], modality="SSS_LF")` from `bluecho.phase1.engine`. CPU uses existing verified model acquisition/import. See README CPU installation.
